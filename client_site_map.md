# Client-Facing Website Sitemap and CMS Editing Map

This document summarizes the public pages on the website, what each page shows, and where the content is edited in the CMS.

## 1. Public Site Map

| Public page | What visitors see | Where to edit in CMS |
|---|---|---|
| Home | Hero area, profile image/banner, artist name, short bio, key skills, latest blog posts, featured music/playlist, and artist story sections | Admin Dashboard for artist name/profile/banner; Manage About for story sections; Manage Blogs for blog posts; Manage Media for music/playlist |
| About | Artist story, hero section, foundation details, expertise list, testimonials, and journey/timeline | Manage About |
| Blog | Listing of blog posts | Manage Blogs |
| Blog post | Full individual blog article | Manage Blogs |
| Events | Upcoming or past events with date, time, location, and description | Manage Events |
| Gallery | Image and video gallery items | Manage Gallery |
| Media | Streaming links, featured playlist, EPs, latest releases, singles, and albums | Manage Media |
| Linktree | Social/marketing links and profile card | Manage Linktree |
| Contact | Contact form and contact details | Contact form submissions are managed in Manage Messages; admin contact email is controlled from the admin account settings |
| Privacy Policy | Legal/privacy information | No dedicated CMS section currently; edit the template directly |
| Terms of Service | Legal terms page | No dedicated CMS section currently; edit the template directly |

## 2. CMS Areas and What They Control

### Admin Dashboard
Use this for the main site identity and branding.
- Artist name
- Short about/bio
- Profile picture
- Banner image
- GA4 analytics settings

### Manage About
Use this for the About page content.
- Hero section
- Foundation section
- Expertise list
- Testimonials
- Journey/timeline items
- Other dynamic About sections

### Manage Blogs
Use this for all blog content.
- Create new blog posts
- Edit existing blog posts
- Delete blog posts

### Manage Events
Use this for public event listings.
- Add event title, description, date, time, and location
- Edit or remove events

### Manage Gallery
Use this for the gallery.
- Upload images
- Add videos
- Remove gallery items

### Manage Media
Use this for the music/discography area.
- Streaming links
- Featured playlist
- EPs
- Latest releases
- Singles
- Albums

### Manage Linktree
Use this for the linktree-style landing page.
- Link buttons
- Link order
- Profile display settings

### Manage Messages
Use this for contact form inquiries.
- View incoming messages
- Mark as read
- Delete messages

## 3. CMS Login Process

If two-factor authentication (2FA) is not enabled:
1. Go to the website login page at /login.
2. Enter the admin email address and password.
3. Click Login.
4. You will be taken straight to the Admin Dashboard.

If 2FA is enabled, after entering the password you will be prompted to enter a 6-digit code from the authenticator app before you can access the dashboard.

## 4. Who Should Use the CMS?

The CMS is intended for the client or website admin who needs to update the site content regularly.

Typical users include:
- The client managing their own content
- An admin or marketing assistant updating blogs, events, and media
- A person responsible for keeping the website up to date

The CMS is mainly used for content updates such as:
- changing artist information
- adding or editing blogs
- updating events
- uploading gallery content
- managing music and linktree links

## 5. Important Note

Some public pages are already connected to the CMS, while others are still static templates. The most important client-facing editable areas are:
- About
- Blogs
- Events
- Gallery
- Media
- Linktree

The Privacy and Terms pages do not currently have a dedicated CMS editing section.
